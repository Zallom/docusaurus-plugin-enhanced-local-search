All components live in the theme and can be imported with `@theme/…`.

| Component | Use |
|---|---|
| [`SearchHero`](./search-hero.md) | Large, ChatGPT-style search bar for a page. |
| [`SearchInput`](./search-input.md) | Mini bar to place anywhere, for example in a swizzled footer. |
| [`SearchBar`](./search-bar.md#searchbar-navbar-bar) | Rendered by the navbar item `{type: 'search'}`. Collapses to an icon button below 997 px. |
| [`SearchPage`](./search-bar.md#searchpage-search-page) | The page added by the `searchPagePath` option. |
| [`SearchModalHost`](./search-bar.md#searchmodalhost-k-without-any-bar) | Mounts the modal and the keyboard shortcuts. Every bar includes it. |
