Docusaurus v3 向けの、タイプミスに強いローカル／オフライン検索です。外部サービスも API キーも、動かすクローラーも必要ありません。インデックスはビルド時にサイトから作成され、検索はブラウザの中で行われます。

:::tip このサイトで試す
このドキュメント自体がデモです。<kbd>⌘</kbd> <kbd>K</kbd>（または <kbd>Ctrl</kbd> <kbd>K</kbd>）を押すか、ナビゲーションバーの検索バーを使うか、[検索ページ](/search)を開いてください。日本語のように単語の間にスペースがない言語でも、単語に分割して検索します。
:::

- **⌘K / Ctrl+K 検索モーダル**：グループ化された結果、ハイライト付きのタイトルと抜粋、キーボード操作、最近の検索とおすすめ。
- **小さな検索バー**：ナビゲーションバー、フッター、または任意のページに配置できます。入力するとその内容でモーダルが開きます。
- **大きな検索バー**：ChatGPT のようなトップページ向けの検索バー。おすすめのキーワードとインライン結果モードがあります。
- **`/search` ページ**（任意）：クエリが URL に残るので、検索結果を共有できます。
- **AI なしで賢い検索**：タイプミスの許容、入力中の前方一致検索、同義語、言語ごとの軽いステミング、ストップワード、アクセントの無視、そして複数の基準による並び替え。
- **ディープリンク**：結果はページではなく、該当するセクション（`/docs/page#見出し`）に直接移動します。
- **カスタムエントリ**：招待リンクや料金ページなど、独自の結果を追加したり、既存のページにキーワードを追加したりできます。言語ごとに翻訳でき、並び順でも優先されます。
- **多言語対応**：言語ごとに 1 つのインデックス、30 言語に翻訳された UI、中国語・日本語・タイ語の単語分割。
- **検索エンジンとブラウザ**：OpenSearch の記述（アドレスバーからサイトを検索）と、任意で schema.org の `SearchAction`。どちらも `/search?q=` を指します。
- **自由にカスタマイズ**：すべてのコンポーネントをスウィズルでき、色は Infima テーマを引き継ぐ CSS 変数で指定します。

## 仕組み

ビルド後、プラグインは各言語で生成されたすべての HTML ページを読み込み、本文を取り出して、`h2` と `h3` の見出し（アンカー付き）ごとにセクションに分けます。そして言語のルートにコンパクトな JSON インデックス（`/search-index.json`、`/ja/search-index.json` など）を書き出します。

最終的な HTML を読むため、Markdown、MDX、React のページを同じ方法で、翻訳されたタイトルごとインデックスできます。

インデックスは、検索バーにカーソルを合わせたとき、フォーカスしたとき、または開いたときに初めてダウンロードされます。70 ページのドキュメントで圧縮後約 70 KB、1 回の検索は 1〜5 ミリ秒です。

自動的に除外されるもの：404 ページ、`noindex` のページ、正規 URL が別の場所を指すページ（重複したドキュメントのバージョン）、Docusaurus が生成する一覧ページ（ブログ一覧、タグ、アーカイブ、著者）。

## 導入事例

- [RaidProtect](https://raidprotect.bot/en)：Discord の保護ボットのドキュメント、用語集、ブログ（5 言語）。
- [Discord FR](https://dfr.gg)：フランス語圏の Discord コミュニティ。
